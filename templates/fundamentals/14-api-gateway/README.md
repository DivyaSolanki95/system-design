# API Gateway

## What is an API Gateway?

An API Gateway acts as a single entry point for all client requests in a microservices architecture.

Instead of clients calling multiple services directly, all requests first go through the API Gateway.

---

## Responsibilities

- Authentication
- Authorization
- Rate Limiting
- Routing
- Logging
- Request Aggregation

---

## Advantages

- Single Entry Point
- Security
- Centralized Logging
- Simplified Client Communication

---

## Spring Boot Connection

Spring Cloud Gateway is commonly used as an API Gateway.
