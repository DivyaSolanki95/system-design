# SQL vs NoSQL

## What is SQL?

SQL databases store data in structured tables with predefined schemas.

Examples:

- MySQL
- PostgreSQL
- Oracle
- SQL Server

---

## What is NoSQL?

NoSQL databases store data in flexible formats like documents, key-value pairs, graphs, or columns.

Examples:

- MongoDB
- Cassandra
- Redis
- DynamoDB

---

## SQL vs NoSQL

| SQL | NoSQL |
|------|--------|
| Fixed Schema | Flexible Schema |
| ACID Transactions | BASE (varies by database) |
| Vertical Scaling | Horizontal Scaling |
| Structured Data | Semi-Structured / Unstructured Data |

---

## When to Use SQL?

- Banking
- ERP Systems
- Inventory
- Financial Applications

---

## When to Use NoSQL?

- Social Media
- Chat Applications
- IoT
- Large Scale Distributed Systems

---

- NoSQL prioritizes scalability and flexibility.
