# DNS Notes

## Definition

DNS stands for Domain Name System.

It converts domain names into IP addresses.

---

## Example

google.com

↓

DNS

↓

142.xxx.xxx.xxx

↓

Google Server

---

## Why DNS?

- Easy to remember
- Faster browsing with caching
- Makes websites easier to access

---
